Hello, welcome to Jack's algorithm practice programme.

Environment setup:

**Windows Platform**:
1. Install VS Code https://code.visualstudio.com/
2. Install build tool MSYS32 https://www.msys2.org/
3. Launch MSYS2 UCRT64 from Start->Menus
4. Inside the ucrt64 shell, execute commands below to install the tools.\
    pacman -S mingw-w64-ucrt-x86_64-gcc \
    mingw-w64-ucrt-x86_64-g++ \
    mingw-w64-ucrt-x86_64-gdb \
    mingw-w64-ucrt-x86_64-git \
    openssh

**Linux Platform**:
You can just use the gcc or g++ to build the code. It's more convenient on linux platform.
